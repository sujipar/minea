# MINEA

[한국어](README.md) · [English](README.en.md)

**안 물어봐도 미리 해 두는 맥 비서.**

메일·문자·화면을 계속 지켜보다가, 해 두면 좋을 일이 보이면 먼저 해 둡니다.

```
메일에 "다음 주 화요일 3시" 가 있으면
   → 화요일 3시 회의, 캘린더에 넣어 둘까요?
```

누르면 해 드리고, 그냥 두면 사라집니다.

## 받기

**[MINEA 받기 →](https://minea.minea.workers.dev)**

macOS 11(Big Sur) 이상 · 애플 실리콘(M1 이후) · 196MB
애플 공증을 받은 파일이라 그냥 열립니다.

**처음 한 번만 더 받는 것이 있습니다.** 받으시면 아무 입력칸에 `@미네아 …` 라고 적어 바로
시키실 수 있습니다. 다만 메일·화면을 **스스로 지켜보게** 하시려면, 나설지 말지를 이 맥 안에서
판단할 모델(약 5.4GB)을 앱에서 단추 한 번으로 받으셔야 합니다.
홈브루도 비밀번호도 필요 없고, 한 번만 하면 됩니다.

## 무엇을 하나요

- **메일과 문자를 계속 봅니다** — 새로 오면 읽고, 약속·마감·답할 것을 골라 둡니다
- **화면을 보고 먼저 말합니다** — 지금 보고 계신 화면에 할 일이 있으면 방울로 알립니다
- **일정과 할 일을 대신 넣습니다** — 캘린더·미리알림에 시간·장소까지 정리해서
- **직접 시킬 수도 있습니다** — 아무 입력칸에나 `@미네아 거래처에 가을 인사 문자 써줘`

## 어디까지 맡길지 정하실 수 있습니다

| | |
|---|---|
| 캘린더·메모·정리 | 묻지 않고 합니다. 되돌릴 수 있는 일이라서요. |
| 답장·메일 보내기 | **써 두기만 합니다.** 보내는 것은 직접 누르십니다. |
| 결제·예약 | **직전에 멈춥니다.** 마지막은 늘 사람이 누릅니다. |

## 값

- **Claude 계정이 있으시면** 그걸로 제한 없이 쓰실 수 있습니다.
- 없으시면 **10회**까지 그냥 써 보실 수 있어요. 카드는 넣지 않으셔도 됩니다.
- 정식 요금은 아직 정하지 않았습니다. 써 보신 분들 이야기를 듣고 정하려 합니다.

## 화면 내용은 어디로도 안 갑니다

나설지 말지는 **이 맥 안에서** 판단합니다. 문자·메일 원문은 이 컴퓨터를 떠나지 않습니다.
밖으로 나가는 것은 「나설 만한 일」로 추려진 몇 줄뿐입니다.

## 웹까지 맡기시려면

크롬에서 claude.ai에 로그인하고 [확장](https://claude.ai/chrome)을 설치하시면 웹사이트도 대신 눌러 드립니다.
Claude 데스크톱 앱이 켜져 있으면 확장 연결을 가져가니, 웹 일을 맡기실 때는 꺼 주세요.
